# MANUS SDK integration

The proprietary MANUS Core SDK is not redistributed in this repository.

Download an SDK version covered by your MANUS agreement from the [MANUS download center](https://docs.manus-meta.com/2.5.0/Resources/), then provide its headers and runtime libraries locally. Do not commit the downloaded SDK, generated logs, device credentials, or vendor binaries.

The teleoperation code can be used without MANUS by selecting another supported input backend.
